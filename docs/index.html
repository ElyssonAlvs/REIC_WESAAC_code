⚖️ Por que a migração de n8n para LangGraph é indispensável?

O n8n provou que o conceito de automação ágil é válido, mas falhou tecnicamente como arquitetura de produção e experimentação científica rigorosa.

Dimensão Técnica No n8n (Paper Original) No LangGraph (Esta Implementação)
Contrato de Dados JSON dinâmico solto via HTTP; sem validação de esquema. Contrato tipado SprintState via Pydantic v2 (fail-fast).
Loops e Negociação Pipelines estáticos; loops cíclicos causam timeouts ou travamentos. Arestas condicionais cíclicas (conditional_edges) para auto-correção.
Validação de Restrições Delegada à LLM (sujeita a alucinação de FTE e prazos). Validador determinístico em Python puro (auditoria sem LLM).
Observabilidade & Métricas Logs visuais no painel n8n; difícil extrair métricas de tokens. LangSmith: telemetria de latência, tokens e árvore de raciocínio.
Testabilidade CI/CD Inviável mockar nós sem executar a plataforma completa. 100% testável com pytest e mocks de LLM em milissegundos.
🧠

O Modelo BDI Concretizado

Em vez de metáforas soltas, o modelo de agência racional (Wooldridge, 2002) foi implementado diretamente nas estruturas de dados:

  • Crenças: O backlog inicial, disponibilidade de FTE e mensagens em SprintState.
  • Desejos: Metas da sprint codificadas nos prompts da técnica BART.
  • Intenções: Alocações confirmadas e plano final aprovado em SprintPlan.
📋

O Padrão Blackboard

Os agentes não conversam ponto a ponto de forma caótica. Eles cooperam através de um quadro compartilhado central:

# Blackboard compartilhado (SprintState)
Agente Priorizador → Escreve tarefas priorizadas
Agente Alocador → Escreve alocação de desenvolvedores
Agente Validador → Audita restrições & registra erros

Planejada

🏛️ Governança de Decisões Arquiteturais (ADRs)

ADR 0001

Migração n8n para LangGraph

Substituição da ferramenta low-code por grafos de estado com loops controlados e contratos tipados.

ADR 0002

Padrão Blackboard & State

Uso de TypedDict + Pydantic v2 e o redutor add_messages para histórico auditável.

ADR 0003

Fábrica Híbrida Groq / Ollama

Desacoplamento de provedor para alternar entre nuvem gratuita ultra-rápida e execução local offline.

ADR 0004

Data Loader & Validação DAG

Ingestão tipada de cenários e detecção algorítmica de ciclos em O(V+E) contra dependências circulares.

⚙️ Comandos de Inicialização com `uv`

O projeto utiliza o gerenciador ultrarrápido uv com runtime Python 3.12:

# 1. Criação e sincronização do ambiente virtual
uv sync Cria .venv e instala deps
# 2. Configurar variáveis de ambiente
copy .env.example .env Windows PowerShell
# 3. Executar toda a suíte de testes com pytest
uv run pytest tests/ -v 37 testes em ~1s

🛠️ Biblioteca de Ferramentas Determinísticas (`sprint_mas.tools`)

Construídas com 22 testes unitários exaustivos e validações defensivas anti-IDOR.

Zero Alucinação Aritmética
calculate_team_capacity

Multiplica fte * sprint_days * points_per_day individual e agregado. Validação defensiva contra FTE < 0 e dias ≤ 0.

Retorno: Dict[dev_id, max_pts]
get_topological_order

Algoritmo de Kahn em tempo linear O(V + E). Valida ausência de dependências órfãs e ciclos no DAG do backlog.

Retorno: List[Task] ordenada
check_allocation_feasibility

Audita soma de story points vs teto individual. Proteção anti-IDOR contra referências a devs ou tarefas inexistentes.

Retorno: {is_feasible, violations}
match_skills

Valida compatibilidade técnica. Regra de domínio: o perfil fullstack atende tanto demandas de backend quanto frontend.

Retorno: bool

Metodologia Científica de Bots

A Metodologia BART (Gerstberger, Silva e Guedes, 2024 — SBC)

Utilizada para estruturar os prompts dos nós cognitivos através de 17 questões em 6 dimensões operacionais:

1. Persona

Identidade, especialidade funcional e tom deliberativo do agente.

2. Gatilho (Trigger)

Evento de transição no grafo que dispara a invocação do nó.

3. Pré-condições

Estado validado exigido no Blackboard antes da execução.

4. Ações

Roteiro deliberativo em passos lógicos numerados (Zero-Shot CoT).

5. Restrições

Guardrails invioláveis (ex: teto de dev_D, DAG acíclico).

6. Pós-condições

Payload JSON canônico injetado de volta no Blackboard.

⚙️ Comandos de Inicialização e Teste com `uv`

Python 3.12

O projeto é integralmente gerenciado via uv, garantindo lockfile determinístico e execução dos testes em menos de um segundo.

# 1. Sincronizar ambiente virtual e dependências
uv sync
# 2. Configurar variáveis de ambiente
copy .env.example .env
# 3. Executar toda a suíte de 90 testes com pytest
uv run pytest tests/ -v
Provedores: PROVIDER=groq para nuvem gratuita ou PROVIDER=ollama para local offline.

Python 3.12

Gerenciamento estrito com uv, ambiente reprodutível e execução de 321 testes.

# 1. Sincronizar ambiente virtual
uv sync
# 2. Rodar todos os 321 testes
uv run pytest tests/ -v
# 3. Executar CLI e trilha BDI (Fase 8)
uv run python main.py --scenario b --show-trace --show-graph
# 4. Executar benchmark dos 3 cenários (Fase 9)
uv run python main.py --benchmark --scenarios a,b,c --runs 2 --export-prefix benchmark
# 5. Avaliação empírica vs manual & LaTeX booktabs (Fase 10)
uv run python main.py --evaluate-human --runs 2 --export-prefix empirical_eval
# 6. Auditoria do Pentágono de Defesa & Segurança (Fase 11)
uv run python main.py --security-audit
# 7. Pacote de reprodutibilidade científica em 1 clique (Fase 12)
uv run python main.py --reproduce-paper --offline-mock
# 8. Extração e agregação de métricas LangSmith (Fase 12)
uv run python main.py --sync-metrics --project REIC_WESAAC_code
Provedor configurável: PROVIDER=groq ou PROVIDER=ollama.
